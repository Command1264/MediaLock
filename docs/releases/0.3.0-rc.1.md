# Media Lock 0.3.0-rc.1

`0.3.0-rc.1` is an unsigned `win-x64` release candidate. It keeps the routing, Recovery, localization, visual,
diagnostic and global-media-key behavior of stable `0.2.0`, then consolidates the completed Playback State Lock,
per-user installer and publish-footprint work.

Status: exact-artifact automated, host and Windows Sandbox validation passed. The
[public GitHub Prerelease](https://github.com/Command1264/MediaLock/releases/tag/v0.3.0-rc.1) was published on
2026-08-26; Stable／Latest remains `0.2.0`.

## Highlights since `0.2.0`

- One-way Playback State Lock with Off and Keep Playing on the current routed target.
- Explicit Media Lock Pause／Play-Pause／Stop, Windows lock-screen controls and a configurable repeated-pause escape
  can turn Keep Playing off without fighting the user.
- An ordinary-user Inno Setup package installs to `%LocalAppData%\Programs\MediaLock\`, appears through Start Menu
  and Windows Search, supports same-path upgrades and uninstall, and retains user data by default.
- The portable ZIP remains supported beside Setup; both containers use the same reviewed self-contained executable.
- Single-file compression reduces the installed／portable executable by 58.91% on the accepted Phase 12B profile while
  preserving all language resources and the no-separate-runtime contract. The outer Setup download is larger because
  it receives an already compressed payload.

## Upgrade from `0.2.0`

Public `0.2.0` shipped only as a portable ZIP. Before moving it or installing this candidate, disable Start with
Windows in the old copy and choose Tray `Exit`. The candidate reuses `%LocalAppData%\MediaLock\` settings and state;
after verifying them, re-enable startup from the installed or final portable path.

The Setup uses a permanent per-user AppId and unversioned install path. Same-version repair and newer-version upgrade
are allowed. An older complete release version, including RC ordering, is blocked rather than overwriting newer
settings. User data survives uninstall by default.

## Supported packages

- Windows 11 x64.
- Portable `MediaLock-0.3.0-rc.1-win-x64.zip` containing one self-contained `MediaLock.exe`.
- Per-user `MediaLock-Setup-0.3.0-rc.1-win-x64.exe` requiring no elevation.
- No separately installed .NET runtime is required.

Both the executable and Setup are unsigned. Windows may therefore show SmartScreen, Smart App Control or reputation
warnings. Installer packaging does not suppress those warnings. Verify the ZIP or Setup SHA-256 before running it.

## Known limitations

- Media Lock cannot set or reliably retain Windows Current Session. It does not promise that a Media Lock-owned card
  replaces or remains first on Windows native media surfaces.
- Routing relies on GSMTC source/session identity and does not inspect browser URLs or guarantee a specific tab inside
  one Chromium source application.
- Keep Playing cannot perfectly attribute a genuine Playing-to-Paused GSMTC transition to a user versus a player that
  reports buffering as Paused; it excludes Changing and duplicate Paused observations and provides bounded overrides.
- The first Playback State Lock is process-lifetime state and does not automatically re-arm after restart or login.
- Automatic updates, code signing, ARM64, volume/mute and customizable shortcuts are not included.
