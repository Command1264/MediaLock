# Media Lock 0.3.0

`0.3.0` is an unsigned `win-x64` stable release that promotes the publicly validated `0.3.0-rc.1` feature set
without adding product behavior. It retains stable `0.2.0` routing, Recovery, localization, visual, diagnostic and
global-media-key behavior, then adds the completed Playback State Lock, per-user installer and compressed publish
profile introduced by RC1.

Status: published as the GitHub [Stable／Latest Release](https://github.com/Command1264/MediaLock/releases/tag/v0.3.0)
on 2026-08-26. The GPG-signed annotated `v0.3.0` tag identifies exact artifact source
`a773fac983728f5d4b2d8cbe40bfad9d1c016737`.

## Highlights since `0.2.0`

- One-way Playback State Lock with Off and Keep Playing for the current routed target.
- Explicit Media Lock Pause／Play-Pause／Stop, Windows lock-screen controls, power suspend and a configurable repeated
  pause escape can turn Keep Playing off without fighting a person who intends to stop audio.
- An ordinary-user Inno Setup package installs to `%LocalAppData%\Programs\MediaLock\`, appears through Start Menu and
  Windows Search, supports same-path repair/upgrade and uninstall, and retains user data by default.
- The portable ZIP remains supported beside Setup; both containers use one reviewed self-contained executable.
- Single-file compression reduces the installed／portable executable while preserving all framework language resources
  and the no-separate-runtime contract.

## Upgrade

The stable Setup uses the same permanent per-user AppId and install path as `0.3.0-rc.1`, so the validated path is an
in-place upgrade that preserves settings, state and an enabled installed-path startup command. Stable Setup supports
same-version repair. After stable is installed, the older RC1 installer is blocked instead of overwriting a newer
complete release version.

Public `0.2.0` shipped only as a portable ZIP. Before moving it or installing stable, disable Start with Windows in the
old copy and choose Tray `Exit`. Stable reuses `%LocalAppData%\MediaLock\`; verify existing settings/state, then
re-enable startup from the installed or final portable path.

## Supported packages

- Windows 11 x64.
- Portable `MediaLock-0.3.0-win-x64.zip` containing one self-contained `MediaLock.exe`.
- Per-user `MediaLock-Setup-0.3.0-win-x64.exe` requiring no elevation.
- No separately installed .NET runtime is required.

The executable and Setup are unsigned. Windows may show SmartScreen, Smart App Control or reputation warnings.
Installer packaging does not suppress them. Run only files attached to the official GitHub Release whose SHA-256
matches its Release body.

## Known limitations

- Media Lock cannot set or reliably retain Windows Current Session and does not promise that its card replaces or
  remains first on Windows native media surfaces.
- Routing does not inspect browser URLs or guarantee one tab inside a Chromium source application.
- Keep Playing cannot perfectly attribute every genuine Playing-to-Paused GSMTC transition to a user versus a player;
  it excludes Changing and duplicate Paused observations and provides bounded overrides.
- Playback State Lock is process-lifetime state and does not automatically re-arm after restart, login or sleep.
- Automatic updates, code signing, ARM64, volume/mute and customizable shortcuts are not included.
