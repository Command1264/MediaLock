# Media Lock 0.2.0

`0.2.0` is the first stable Media Lock release. It promotes the complete behavior independently validated through
`0.2.0-rc.3` without adding a new product feature between the final candidate and stable release.

## Highlights

- Windows Auto, Priority Rules, App Lock and Session Lock routing modes.
- Global physical-media-key capture, consumption and routing to the resolved target.
- Recovery across Session recreation, lock/unlock and sleep/resume.
- Bilingual English/Traditional Chinese WPF interface with Windows, Light and Dark themes.
- Routed-target artwork, timeline and one-commit absolute Seek where the Session advertises support.
- Notification-area lifecycle, single-instance activation and optional current-user login startup.
- Privacy-safe About and diagnostics surface with bounded JSONL logs.

## Supported package

- Windows x64.
- Self-contained, single-file `MediaLock.exe` inside a versioned ZIP.
- No separately installed .NET runtime is required.
- Ordinary-user execution is the supported default.

## Known limitations

- The executable is unsigned, so Windows reputation or SmartScreen warnings remain possible.
- Routing relies on GSMTC source/session identity and does not inspect browser URLs.
- Browser integration, customizable shortcuts, volume, mute, Playback State Lock and Windows Media Surface Mirror are
  not included.
- Application and hardware compatibility claims require a named passing test row.
