# Media Lock 0.2.0-rc.2

`0.2.0-rc.2` is the second unsigned `win-x64` release candidate. It consolidates the features and fixes completed
after the first packaged candidate and is published as a GitHub Prerelease. The executable remains unsigned even
though the annotated Git tag is GPG-signed.

## Highlights since `0.2.0-rc.1`

- English and Traditional Chinese UI, with language-native choice names and immediate application after Save.
- Windows, Light and Dark themes; refreshed Windows 11-inspired controls, modal Settings and theme-aware main caption.
- Routed-target artwork, elapsed/total time and an interactive timeline.
- Absolute Seek through the same Router boundary as transport commands, with local gesture preview and one commit on
  release.
- Production global interception for Play/Pause, Previous, Next and Stop, including repeat suppression, safe
  pass-through and capture-time target preservation.
- Stable Session selection across Recovery and Session-key recreation without silently selecting an unrelated row.
- Immediate validation of Recovery timeout input and shared rounded control styling.

## Supported package

- Windows x64.
- Self-contained, single-file `MediaLock.exe` inside a versioned ZIP.
- No separately installed .NET runtime is required.
- Ordinary-user execution is the supported default.

## Known limitations

- The candidate is unsigned, so Windows reputation or SmartScreen warnings remain possible.
- Routing relies on GSMTC source/session identity. Media Lock does not inspect browser URLs and cannot promise a
  particular tab when a browser exposes multiple tabs through one shared Session.
- Browser integration, customizable shortcuts, volume and mute controls are not included.
- Application and hardware compatibility claims require a named passing test row; a player's advertised GSMTC
  capability does not guarantee that the player honors every command.
