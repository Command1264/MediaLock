# Media Lock 0.2.0-rc.3

`0.2.0-rc.3` is the third unsigned `win-x64` release candidate. It retains the complete routing and desktop behavior
from `0.2.0-rc.2` and adds an in-app support surface for identifying the running build and collecting a minimal,
privacy-safe diagnostic summary.

## Highlights since `0.2.0-rc.2`

- A bilingual, themed About and diagnostics card inside Settings.
- Executable version, Windows product/display/build/architecture, prerelease/stable state and embedded-signature state.
- One-click privacy-safe diagnostics copied from an explicit allowlist using native Windows line endings.
- Diagnostics distinguish an active media-key hook from disabled or unavailable interception.
- Actions to open the bounded JSONL log directory, repository support page and canonical bug-report form.
- Updated repository Topics that describe the actual Windows/.NET/WPF/GSMTC/media-routing scope.

## Privacy boundary

The standard copied summary excludes media title, artist, account name, full path, persisted target identity and the
complete settings document. Users should still review copied text before sharing it publicly. Raw `logs\*.jsonl` files
remain separate diagnostic material and are not copied automatically.

## Supported package

- Windows x64.
- Self-contained, single-file `MediaLock.exe` inside a versioned ZIP.
- No separately installed .NET runtime is required.
- Ordinary-user execution is the supported default.

## Known limitations

- The executable is unsigned, so Windows reputation or SmartScreen warnings remain possible.
- Routing relies on GSMTC source/session identity and does not inspect browser URLs.
- Browser integration, customizable shortcuts, volume and mute controls are not included.
- Application and hardware compatibility claims require a named passing test row.

## Verification and publication status

Build and validation instructions are in the [release candidate runbook](../release-candidate.md). Candidate evidence
must identify the exact source commit and archive SHA-256; earlier RC evidence does not apply.

`0.2.0-rc.3` is not yet published. Until its independent host and Windows Sandbox gates pass and publication is
separately approved, the current public download remains
[Media Lock 0.2.0-rc.2](https://github.com/Command1264/MediaLock/releases/tag/v0.2.0-rc.2).
